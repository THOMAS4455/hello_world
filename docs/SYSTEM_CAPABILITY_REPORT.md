# 系统能力报告（Stock Prediction System）

> 生成日期：2026（会话内实测结论汇总）。本文档如实记录系统当前「能做什么 / 不能做什么」，以及支撑结论的数据证据。

## 一、执行摘要

系统是一个 **A 股研究/预测平台**（FastAPI + React），具备完整的数据→特征→预测→回测→选股→风控闭环。经过本会话的系统化验证：

- ✅ **工程能力完整**：真实数据、前复权、真实成本、回测、选股、持仓建议、模拟盘、风控、因子研究、防过拟合评估——基础设施齐全。
- ❌ **预测/选股的 alpha 未得到验证**：三种方法（ML 方向预测、动量因子、GBDT+Alpha158）都**没有稳定、可信的正 IC**。
- ✅ **风控是确定有用的**：不依赖预测，能控回撤、管仓位、算真实成本。

**一句话定位**：系统现在是一个「**能诚实评估策略、能控风险的研究工具**」，但**还不是一个能稳定盈利的选股系统**。

## 二、系统概况

- **后端**：FastAPI（`api/` 路由层 → `flask_services/` 服务层 → `src/` 领域层）
- **前端**：React 18 + Redux Toolkit + react-router
- **数据**：AKShare / 东财 / 新浪 / 腾讯，日线 **前复权(qfq)**，SQLite + JSON 存储
- **预测**：`ImprovedPredictor` 三层模型（baseline 树 / enhanced / regime 路由），LightGBM/XGBoost/CatBoost/LSTM 可选
- **评估**：IC / ICIR / RankIC + PSR / Deflated Sharpe / PBO（防回测过拟合）

## 四、实测性能数据

### 4.1 预测/因子的 IC 实测

| 方法 | IC 均值 | IC t 值 | 判定 |
|---|---|---|---|
| ML 方向预测（vs 多数类基线） | 超额 -2.25% | — | ❌ 无 edge |
| 动量因子（20/60d·5d） | -0.021 | -1.0 | ❌ 无 edge |
| 动量因子（60/120d·20d） | -0.068 | -1.6 | ❌ 无 edge |
| GBDT+Alpha158（单次切分，最近1年） | +0.142 | 7.65 | ⚠️ 假象（只测牛市段） |
| GBDT+Alpha158（walk-forward 全程） | +0.091 | 11.3 | ⚠️ 不稳定 |

### 4.2 GBDT+Alpha158 walk-forward 分年 IC

| 年份区间 | IC 均值 | IC t 值 | 显著？ |
|---|---|---|---|
| 2022–2023 | +0.012 | 0.75 | ❌ 不显著（≈抛硬币） |
| 2023–2024 | +0.083 | 6.17 | ✅ |
| 2024–2025 | +0.129 | 8.53 | ✅ |
| 2025–2026 | +0.140 | 7.63 | ✅ |

> 结论：GBDT+Alpha158 的 IC **逐年上升**，在 2022–2023 年（熊/震荡）≈0、失效；只在近 3 年成立。属**时灵时不灵**，非稳健 alpha。

### 4.3 泄漏检查

- 纯随机游走（无信号）合成数据 → IC = -0.027、t = -1.5、门槛不通过。
- 说明回测/评估代码**无前视泄漏**，上面的负/不稳定结论是真实数据特性，不是 bug。

## 五、关键结论

1. **三种"预测/选股"路径都没有稳定 alpha**（证据见 4.1）。
2. **唯一接近的 GBDT 信号不稳定**（4.2）：无法预知何时失效，不能作为实盘依据。
3. **风控是唯一确定有效的能力**：不靠预测，靠纪律（回撤熔断、仓位约束、真实成本）实现「少亏、控回撤」。

## 七、已知限制与风险

1. **幸存者偏差**：只测当前存活股票，正收益结论需打折 20–50%。
2. **样本偏大盘**：只测了市值最大 100 只；中小盘未测（动量/反转在小盘通常更强）。
3. **日线粒度**：无分钟/盘口数据，无法做日内。
4. **做空受限**：A 股做空难，「多空」收益部分不可实现，只能做多。
5. **单模型样本小**：已结算信号仅 8 条，回测结论仍需更大样本确认。

## 八、定位与建议

**定位**：风险可控的研究/指数增强工具，而非「稳赚预测机」。

**建议优先级**（若继续投入）：
1. 换样本 → 中小盘（中证 500/1000 成分）重测动量/反转。
2. 换因子方向 → 专门做短期反转（2022 震荡市反转可能更强）。
3. 若以上仍无 alpha → 停止预测投入，聚焦风控层做「指数增强 + 资本保全」。

**诚实声明**：在「散户级数据 + 日线 + 大盘股」约束下，当前未找到稳健 alpha；继续投入前需明确这一点。
