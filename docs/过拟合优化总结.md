## 优化技术总结

### 1. 模型复杂度控制
```python
# 树模型
n_estimators: 160 → 100 → 80
max_depth: 10 → 8 → 3-8
min_samples_split: 2 → 10 → 15
min_samples_leaf: 1 → 5 → 8

# 梯度提升
learning_rate: 0.05 → 0.03 → 0.02
num_leaves: 31 → 15 → 10
```

### 2. 正则化强化
```python
# L1/L2正则化
reg_alpha: 0.1 → 1.0 → 2.0
reg_lambda: 0.1 → 2.0 → 3.0
l2_leaf_reg: 3.0 → 5.0 → 8.0

# Logistic Regression
C: 1.0 → 0.1 (更强的正则化)
```

### 3. 随机性增加
```python
subsample: 0.8 → 0.7 → 0.6
colsample_bytree: 0.8 → 0.7 → 0.6
bagging_temperature: 0.5 → 0.3 → 0.2
```

### 4. 类别不平衡处理
```python
class_weight='balanced'  # 所有模型
scale_pos_weight=4.0  # XGBoost (匹配4:1比例)
auto_class_weights='Balanced'  # CatBoost
```
