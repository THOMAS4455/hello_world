# 幸存者偏差说明（Survivorship Bias）

**状态**：已知限制，尚未完全解决（2026 年标注）。

## 问题

当前历史数据（AKShare `stock_zh_a_hist`）只能取到**当前仍存续**的股票。已退市、被并购、
长期停牌的股票不在回测样本中。这会让任何基于历史数据的回测**系统性高估**收益，尤其是：

- 动量/趋势因子：会错过「强势后暴跌退市」的样本；
- 方向预测：会错过「长期阴跌」的样本。

## 当前缓解措施

1. 回测必须**跨多年、多股票**（而非单只 1 年），并在报告中标注覆盖范围与样本数。
2. 所有结论以**相对基准的超额收益 / IC / ICIR / 夏普 / 最大回撤**为准，不只看绝对收益或「准确率」。
3. 因子回测对「当前存活」股票做，明确**不声称代表全市场**。

## 待办（彻底解决需要）

- 获取历史成分股名单（含退市股）——可用 AKShare 退市股接口或第三方库（如 tushare 历史退市列表）。
- 用 point-in-time 成分构建，避免前视。

## 影响评级

- 对「稳健性结论」：**高影响**。在拿到退市股名单前，任何正收益结论都应**打折 20–50% 看待**，
  且仅用于研究，不构成实盘依据。
